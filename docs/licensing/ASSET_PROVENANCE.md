# Asset Provenance

Every external research resource should have traceable origin before it is included in a public release.

Recommended fields:

- asset name;
- version or date;
- provider or author;
- source location;
- integrity hash;
- license or terms reference;
- redistribution status;
- modification status;
- project purpose;
- review status.

Suggested review states: `CONFIRMED`, `PENDING`, `RESTRICTED`, `UNKNOWN`.

If provenance or publication rights are unresolved, keep the resource outside the public repository and document only the research finding when appropriate.
