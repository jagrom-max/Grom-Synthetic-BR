# Dataset License Policy

Generated datasets are versioned research artifacts and may have terms different from the source-code license.

Before a public dataset release, the project should document:

- generator version and commit;
- generation configuration;
- input provenance;
- applicable licenses;
- integrity hashes;
- dataset manifest;
- known limitations;
- intended research use;
- separation from independent evaluation data.

No dataset release should contain material whose publication rights are unresolved.

Training data and independent validation or golden-set data should remain clearly separated.
