# Security Policy

Grom Synthetic BR is research software. Please report security concerns responsibly and avoid publishing sensitive details before they can be reviewed.

## Please include

- affected version or commit;
- reproduction steps;
- expected and observed behavior;
- impact;
- suggested correction, if known.

## Do not include

Do not place credentials, private keys, personal data, confidential records or restricted datasets in issues, pull requests, screenshots or test artifacts.

## Supply-chain and provenance

Dependency integrity, unexpected package changes, altered hashes, untrusted assets and provenance failures are relevant security concerns for this project.

Correctness questions involving OCR quality, synthetic realism or normative interpretation are normally handled as research issues rather than security issues.
